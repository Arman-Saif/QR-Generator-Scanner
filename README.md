
# QR Generator & Scanner

A lightweight, modern React application built with Vite and Material-UI (MUI) that allows users to seamlessly generate custom QR codes and scan existing ones using their device camera.

---

## 🚀 Inspiration & Purpose
This project was built as a hands-on experience to practice React fundamentals, component state management, integration with modern JavaScript libraries, and mobile-friendly web development. 

---

## ✨ Features

* **QR Code Generation:** Generate a QR code dynamically by providing any combination of your Name, Phone Number, Email, and Website address.
* **Live QR Scanning:** Use your device's camera to scan QR codes on the fly.
* **Structured Data Rendering:** Automatically parses scanned data and displays it cleanly inside an interactive Material-UI card layout.
* **Bottom Navigation:** Smooth switching between the Generator and Scanner views.

### 🔮 Future Roadmap
* **Image Upload:** Ability to upload an existing QR code image from your device to scan it.
* **Card Download:** Option to download your generated QR code or contact card as an image.

## 📦 Installation & Setup

Make sure you have [Node.js](https://nodejs.org/) installed on your machine. You can use either `npm` or `yarn` to run the project.

### 1. Clone the repository
```bash
git clone https://github.com/Arman-Saif/QR-Generator-Scanner.git
cd your-repo-name

2. Install dependencies
Using npm:
npm install

(Or using yarn):
yarn install

3. Run the development server
Using npm:
npm run dev

(Or using yarn):
yarn dev

Open your browser or mobile device view (via local network link provided in the terminal) to test the app!
🛠️ Built With
 * React (via Vite)
 * Material-UI (MUI) & Emotion (for UI styling and icons)
 * qrcode (Soldair's Node-QRCode generator)
 * qr-scanner (Nimiq QR scanner library)
